# Ticketing-System-Lab-Setup
- This lab focuses on setting up and working with a ticketing system in a simulated IT support environment. I created the lab while going through TCM Security's Practical Help Desk Associate (PHDA) training.
- The goal was to gain hands-on experience with common help desk workflows, including:
  - 🎫 Creating and managing support tickets
  - 🔎 Troubleshooting user-reported issues
  - 📝 Documenting problems and resolutions
  - 🔄 Tracking ticket status and progress
  - 💻 Practicing real-world IT support scenarios
- This lab helped me understand how ticketing systems are used to organize, prioritize, and resolve technical support requests in an IT environment.
